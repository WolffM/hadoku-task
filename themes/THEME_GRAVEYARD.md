# Theme Graveyard

This document contains archived themes that are no longer active in the Hadoku Theme System.

## Kitsune Theme Contest (2025)

The Kitsune Theme Contest had 4 contestants competing for a permanent spot in the theme lineup. The winner was **Kitsune Springs D**, which has been renamed to **Izakaya** and promoted to the main theme collection.

### Winner: Izakaya (formerly Kitsune Springs D)

- **Status**: Active theme (izakaya-light, izakaya-dark)
- **Colors**: Teal/turquoise primary with warm peachy backgrounds
- **Vibe**: Cozy Japanese bar aesthetic with modern touches

## Restoring Archived Themes

If you want to restore any of these themes:

1. Copy the CSS from this document
2. Add it back to `themes/src/style.css`
3. Add the theme names to `THEMES` array in `themes/src/index.ts`
4. Update `ThemeName` type in `src/app/types.ts`
5. Add theme family entry in `src/app/themeConfig.tsx`
6. Rebuild the themes package: `npm run build`
